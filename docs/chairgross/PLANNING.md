# 체어그로스 (Chairgross) 서비스 기획

> 작성일: 2026-09-15
> 상태: 초안 (v0.1) — 검증 필요한 가정 포함

## 0. 프로젝트 배경

프랜차이즈 본사에서 일하며 회사의 성장을 위해 개인 시간과 에너지를 계속 희생해온 데서 오는 무기력감을 해소하고, **나를 위한 일**을 만드는 것이 이 프로젝트의 출발점이다.

장기 목표:
1. 체어그로스(또는 공동구매 중계 등 다른 사이드 프로젝트)를 통해 안정적인 부수입 구조를 만든다.
2. 수익이 궤도에 오르면 아내가 먼저 휴직하도록 한다.
3. 이후 본인도 점진적으로 본업을 정리하고 전업 전환하여, 일과 가족 시간의 비중을 스스로 조절할 수 있는 삶으로 옮겨간다.

즉 이 프로젝트는 "빨리 크게"보다 **적은 리소스로 검증 → 점진적 확장**이 우선순위다. 본업을 유지한 채 퇴근 후/주말 시간으로 진행 가능한 범위로 MVP를 설계한다.

## 1. 서비스 정의

> **2026-09-16 업데이트**: 라이브엑스(위닛헤어스튜디오)의 디자이너 매출 진단 리포트를 벤치마킹한 뒤, **C안(디자이너 매출 성장 진단·코칭 SaaS)으로 방향을 확정**했다. A안/B안은 초기 검토 기록으로 남겨둔다. 상세 벤치마킹 근거는 10장, 확정된 설계 원칙은 11장 참고.

### C안. 디자이너 매출 성장 진단·코칭 SaaS (확정)
헤어디자이너가 스스로 입력한 매출/고객 데이터를 바탕으로, 매달(또는 매주) **원인 분해 + 기준 대비 진단 + 실행 계획**을 자동 생성해주는 서비스. "Chair(디자이너의 자리) + Grows(성장)"라는 이름 그대로, 디자이너 개인의 성장을 코칭하는 도구다. 상세 내용은 10~12장 참고.

### A안. B2C 구독 멤버십 (초기 검토, 보류)
고객이 월 구독료를 내면 제휴 미용실에서 정해진 시술(커트, 클리닉/트리트먼트 등)을 정가보다 저렴하게 또는 월 1~2회 무료로 이용할 수 있는 멤버십. 플랫폼은 제휴 미용실로부터 이용 건당 수수료 또는 월 입점료를 받는다.

- 고객 Pain: 미용실 방문 주기가 들쭉날쭉하고, 매번 비용 부담이 있음. 단골 관리가 안 됨.
- 미용실 Pain: 신규 고객 유입이 어렵고, 재방문율(리텐션)이 낮음. 예약 공백(비는 시간대) 관리가 안 됨.

### B안. B2B 체어(좌석) 렌탈/구독
프리랜서 헤어디자이너가 매장 체어(좌석)를 월 구독료로 빌려서 독립적으로 영업하는 "공유 오피스형" 미용실. 매장주는 유휴 체어로 고정 수익을 얻고, 디자이너는 초기 창업 비용 없이 독립한다.

- 이 모델은 부동산/매장 운영이 얽혀 있어 초기 검증 난이도와 운영 부담이 A안보다 높음.
- 다만 "체어그로스(Chair+Grows)"라는 이름 자체는 B안과 더 직결된다는 점은 고려할 부분.

> A/B안은 모두 보류. 이후 문서는 C안 기준으로 작성.

## 2. 타겟 고객

- **1차 타겟 (수요자)**: 20~40대, 특정 동네에 고정 출근/생활권이 있어 반복 방문이 가능한 직장인. 커트/펌/클리닉을 정기적으로 받는 그룹.
- **2차 타겟 (공급자)**: 신규 오픈했거나 예약 공백이 많은 동네 미용실 원장(1인샵 ~ 소규모 매장). 대형 프랜차이즈보다 자체 마케팅 여력이 부족한 개인 매장이 초기 제휴처로 적합 (본업에서 얻은 프랜차이즈 업계 이해가 강점으로 작용할 수 있는 지점).

## 3. 핵심 기능 (MVP 범위)

본업을 병행하며 만들 수 있는 최소 범위로 한정한다.

1. **제휴 미용실 리스트/상세 페이지**: 위치, 시술 종류, 구독 혜택 내용 노출
2. **구독 가입 및 결제**: 월 정액 구독 (PG 연동 — 토스페이먼츠/아임포트 등)
3. **이용권 사용 처리**: 매장 방문 시 QR/코드로 구독 혜택 사용 확인 (원장이 사용 처리)
4. **예약(선택)**: 초기엔 예약은 전화/카카오 채널로 넘기고, 플랫폼은 "혜택 확인"에만 집중 — 예약 시스템은 Phase 2로 미룬다.
5. **관리자(원장용) 대시보드**: 이번 달 방문/정산 내역 확인

의도적으로 제외(Phase 2+): 실시간 예약/캘린더 연동, 리뷰/평점, 포인트 적립, 다지점 프랜차이즈 관리 기능.

## 4. 수익 모델

- 고객: 월 구독료 (예: 19,900원~39,900원, 등급별 시술 범위 차등)
- 미용실: 구독 고객 방문 1건당 정산 수수료(예: 시술가의 10~15%) 또는 월 고정 입점료 — 초기엔 무료/저가로 입점 유치 후 수수료 모델 전환 권장
- 초기엔 수익보다 **제휴 매장 수 & 재구독률** 검증이 우선

## 5. 유사 서비스 벤치마크 (조사 필요)

국내 미용실 구독/멤버십 서비스, 헤어샵 예약 플랫폼(네이버 예약, 카카오헤어샵 등)이 이미 자리잡고 있어 **차별점**을 명확히 해야 한다. 예약이 아니라 "구독으로 방문 주기와 비용을 고정한다"는 지점이 차별점이 될 수 있는지 실사용자 인터뷰로 검증 필요.

## 6. 로드맵

| Phase | 목표 | 산출물 |
|---|---|---|
| 0 (현재) | 모델 확정, 오프라인 검증 | 이 문서 확정 + 동네 미용실 3~5곳 인터뷰 |
| 1 | MVP 구축 | 랜딩페이지(수요 검증용) → 실사용 웹앱(제휴 1~3곳) |
| 2 | 소규모 운영 | 제휴처 10곳, 결제/정산 자동화 |
| 3 | 확장 | 예약 연동, 지역 확장, 마케팅 자동화 |

Phase 1 시작 전에, 코드보다 먼저 **랜딩페이지 + 사전 신청/인터뷰**로 수요를 확인하는 것을 권장한다 (본업 병행 시 리소스 최소화 관점에서도 유리).

## 7. 기술 스택 (제안)

- 프론트: Next.js (React) — 랜딩페이지와 웹앱을 하나의 레포에서 단계적으로 확장하기 용이
- 백엔드/DB: Next.js API Routes + Supabase (Postgres, Auth, Storage) — 초기 인프라 운영 부담 최소화
- 결제: 토스페이먼츠 정기결제(빌링) API
- 배포: Vercel

이 스택은 1인 개발 + 야간/주말 작업에 적합하도록 운영 부담이 적은 조합 위주로 선정했다.

## 10. 벤치마킹 분석: 위닛헤어스튜디오(라이브엑스) 매출 진단 리포트

라이브엑스가 위닛헤어스튜디오 디자이너에게 제공 중인 "AI 매출 분석 리포트"(2026.08월 사례)를 검토했다. 구조는 다음 흐름을 따른다: **① 한 줄 진단 → ② 원인을 금액으로 분해 → ③ 내부 기준 대비 GAP·등급 판정 → ④ 성장여력을 금액으로 환산 → ⑤ 90일 단계별 실행계획 → ⑥ 주간 실행 체크리스트 → ⑦ 산식/해석 범위 고지**.

### 착안할 점 (그대로 가져올 가치)
- **결론을 먼저 제시**: 지표 나열이 아니라 "무엇이 진짜 문제인지"를 한 문장으로 먼저 던짐
- **원인을 %가 아니라 금액으로 분해**: 실행 동기를 강하게 만듦
- **기준 대비 등급 라벨링**(우수/양호/보완/개선/핵심리스크): 숫자를 즉각적인 판단으로 변환
- **성장여력의 반사실적(counterfactual) 계산**: "이 지표만 고치면 +OO만원" — 매우 강한 동기부여 장치
- **전략 → 주간 체크리스트로 계층적 분해**: 전략만 던지고 끝나지 않고, 사람이 매일/매주 실행할 수 있는 단위까지 쪼갬
- **산식·해석 범위를 스스로 고지**: 과신·과장을 피하고 신뢰를 확보하는 장치

### 한계 / 체어그로스가 더 잘할 수 있는 지점
- 정적 월간 PDF 1회성 리포트 — 진행 추적·피드백 루프가 없음
- 비교 기준이 고정값 하나뿐 — 동료/유사 디자이너 대비 상대 비교가 없음
- 진단만 있고 실행 도구(메시지 발송 등)로 연결되지 않음
- 지난달 처방의 이행 여부를 다음 리포트가 되짚어주지 않음 — 성장 스토리가 누적되지 않음
- 단일 디자이너/매장 단위 — 여러 매장을 묶는 본사·원장 시점 뷰가 없음

## 11. 핵심 설계 원칙

- **외부 예약/POS 시스템 연동 금지**: 네이버예약·카카오헤어샵·매장 POS 등 외부 시스템과의 데이터 연동은 하지 않는다. 이는 이번에 새로 정한 제약이 아니라 앞서 합의한 원칙이며, 계속 유지한다. 모든 데이터는 디자이너의 **자가 입력**을 기반으로 한다.
  - 이 원칙 때문에 데이터 자동 수집, 실시간 동기화, 예약 시스템에 직접 꽂는 자동화(예: 자동 문자 발송)는 MVP 범위에서 제외한다.
  - 대신 "복사해서 바로 보낼 수 있는 메시지 템플릿"처럼, 연동 없이도 실행력을 높이는 방식으로 우회한다.

## 12. 지금 바로 적용 가능한 요소 (연동 없이 구현 가능, MVP 우선순위)

외부 시스템 연동 없이, 디자이너의 자가 입력만으로 구현 가능한 요소를 우선순위로 정리했다.

| 우선순위 | 요소 | 내용 |
|---|---|---|
| 1 | **자가입력 기반 진단 엔진** | 디자이너가 월/주 단위로 총매출, 접객수(신규/재방문), 선불권 판매액 등 핵심 수치를 직접 입력하면, 원인 분해 + 기준 대비 등급 판정 + 성장여력 계산까지 자동 생성. 연동 없이도 핵심 가치의 대부분을 구현 가능한 부분 — MVP의 중심.
| 1 | **판정 등급 룰 엔진** | 지표별 우수/양호/보완/개선/핵심리스크 등급을 매기는 기준값 — 초기엔 업계 통상 기준을 수동으로 세팅, 데이터가 쌓이면 보정 |
| 1 | **성장여력 계산기** | "이 지표만 개선하면 +OO만원" 반사실적 계산 — 수식만 있으면 구현 가능 |
| 2 | **90일 실행계획 + 주간 체크리스트 자동 생성** | 진단 결과에 매칭되는 사전 정의된 액션 플레이북에서 전략 문구를 자동 조합 (규칙 기반 템플릿) |
| 2 | **재예약/이탈고객 대응 메시지 템플릿** | 카톡/문자로 디자이너가 직접 복사해 보낼 수 있는 스크립트 세트 제공 — 예약 시스템에 꽂지 않고도 실행력을 높이는 우회 방법 |
| 2 | **전월 처방 이행 체크 + 피드백 루프** | 다음 달 입력 시 "지난달 제안했던 목표를 실행했는지" 체크 항목 추가 — 성장 사례가 누적되는 구조의 시작점 |
| 3 | **동료 디자이너 상대 비교(퍼센타일)** | 여러 디자이너가 같은 폼으로 자가입력하면 그 데이터끼리 상대 비교 가능 — 표본이 어느 정도 쌓인 후(Phase 2) 적용 |
| 3 | **매장/브랜드 단위 롤업 뷰** | 여러 디자이너의 자가입력 데이터를 모아 원장/본사 시점으로 집계 — 본업(프랜차이즈 본사) 경험을 살릴 수 있는 지점 |

**MVP 최소 구현안**: 1순위 3개 항목만으로도 리포트의 핵심 가치(뾰족한 진단)를 검증할 수 있다. 코드 없이 스프레드시트(수식)로 먼저 프로토타입을 만들어 실제 디자이너 1~2명에게 리포트를 생성해주고 반응을 검증한 뒤, 웹 폼 + 자동 생성으로 옮기는 순서를 권장한다.
