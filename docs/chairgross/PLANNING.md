# 체어그로스 (Chairgross) 서비스 기획

> 작성일: 2026-09-15
> 상태: 초안 (v0.1) — 검증 필요한 가정 포함

## 0. 프로젝트 배경

프랜차이즈 본사에서 일하며 회사의 성장을 위해 개인 시간과 에너지를 계속 희생해온 데서 오는 무기력감을 해소하고, **나를 위한 일**을 만드는 것이 이 프로젝트의 출발점이다.

장기 목표:
1. 체어그로스(또는 공동구매 중계 등 다른 사이드 프로젝트)를 통해 안정적인 부수입 구조를 만든다.
2. 수익이 궤도에 오르면 아내가 먼저 휴직하도록 한다.
3. 이후 본인도 점진적으로 본업을 정리하고 전업 전환하여, 일과 가족 시간의 비중을 스스로 조절할 수 있는 삶으로 옮겨간다.

즉 이 프로젝트는 "빨리 크게"보다 **적은 리소스로 검증 → 점진적 확장**이 우선순위다. 본업을 유지한 채 퇴근 후/주말 시간으로 진행 가능한 범위로 MVP를 설계한다.

## 1. 서비스 정의 (가정 — 확인 필요)

"미용실 플랫폼(구독 서비스)"라는 방향에서, 두 가지 사업 모델이 가능하다. 아래 A안을 기본 가정으로 문서를 작성했고, B안도 함께 정리해둔다. **어느 쪽인지 확정이 필요하다.**

### A안. B2C 구독 멤버십 (기본 가정)
고객이 월 구독료를 내면 제휴 미용실에서 정해진 시술(커트, 클리닉/트리트먼트 등)을 정가보다 저렴하게 또는 월 1~2회 무료로 이용할 수 있는 멤버십. 플랫폼은 제휴 미용실로부터 이용 건당 수수료 또는 월 입점료를 받는다.

- 고객 Pain: 미용실 방문 주기가 들쭉날쭉하고, 매번 비용 부담이 있음. 단골 관리가 안 됨.
- 미용실 Pain: 신규 고객 유입이 어렵고, 재방문율(리텐션)이 낮음. 예약 공백(비는 시간대) 관리가 안 됨.

### B안. B2B 체어(좌석) 렌탈/구독
프리랜서 헤어디자이너가 매장 체어(좌석)를 월 구독료로 빌려서 독립적으로 영업하는 "공유 오피스형" 미용실. 매장주는 유휴 체어로 고정 수익을 얻고, 디자이너는 초기 창업 비용 없이 독립한다.

- 이 모델은 부동산/매장 운영이 얽혀 있어 초기 검증 난이도와 운영 부담이 A안보다 높음.
- 다만 "체어그로스(Chair+Grows)"라는 이름 자체는 B안과 더 직결된다는 점은 고려할 부분.

> **Decision 필요**: A안(소비자 구독 멤버십) vs B안(디자이너 체어 렌탈) 중 어느 쪽으로 갈지, 혹은 A→B 순서로 확장할지 결정 필요. 이후 문서는 A안 기준으로 작성.

## 2. 타겟 고객

- **1차 타겟 (수요자)**: 20~40대, 특정 동네에 고정 출근/생활권이 있어 반복 방문이 가능한 직장인. 커트/펌/클리닉을 정기적으로 받는 그룹.
- **2차 타겟 (공급자)**: 신규 오픈했거나 예약 공백이 많은 동네 미용실 원장(1인샵 ~ 소규모 매장). 대형 프랜차이즈보다 자체 마케팅 여력이 부족한 개인 매장이 초기 제휴처로 적합 (본업에서 얻은 프랜차이즈 업계 이해가 강점으로 작용할 수 있는 지점).

## 3. 핵심 기능 (MVP 범위)

본업을 병행하며 만들 수 있는 최소 범위로 한정한다.

1. **제휴 미용실 리스트/상세 페이지**: 위치, 시술 종류, 구독 혜택 내용 노출
2. **구독 가입 및 결제**: 월 정액 구독 (PG 연동 — 토스페이먼츠/아임포트 등)
3. **이용권 사용 처리**: 매장 방문 시 QR/코드로 구독 혜택 사용 확인 (원장이 사용 처리)
4. **예약(선택)**: 초기엔 예약은 전화/카카오 채널로 넘기고, 플랫폼은 "혜택 확인"에만 집중 — 예약 시스템은 Phase 2로 미룬다.
5. **관리자(원장용) 대시보드**: 이번 달 방문/정산 내역 확인

의도적으로 제외(Phase 2+): 실시간 예약/캘린더 연동, 리뷰/평점, 포인트 적립, 다지점 프랜차이즈 관리 기능.

## 4. 수익 모델

- 고객: 월 구독료 (예: 19,900원~39,900원, 등급별 시술 범위 차등)
- 미용실: 구독 고객 방문 1건당 정산 수수료(예: 시술가의 10~15%) 또는 월 고정 입점료 — 초기엔 무료/저가로 입점 유치 후 수수료 모델 전환 권장
- 초기엔 수익보다 **제휴 매장 수 & 재구독률** 검증이 우선

## 5. 유사 서비스 벤치마크 (조사 필요)

국내 미용실 구독/멤버십 서비스, 헤어샵 예약 플랫폼(네이버 예약, 카카오헤어샵 등)이 이미 자리잡고 있어 **차별점**을 명확히 해야 한다. 예약이 아니라 "구독으로 방문 주기와 비용을 고정한다"는 지점이 차별점이 될 수 있는지 실사용자 인터뷰로 검증 필요.

## 6. 로드맵

| Phase | 목표 | 산출물 |
|---|---|---|
| 0 (현재) | 모델 확정, 오프라인 검증 | 이 문서 확정 + 동네 미용실 3~5곳 인터뷰 |
| 1 | MVP 구축 | 랜딩페이지(수요 검증용) → 실사용 웹앱(제휴 1~3곳) |
| 2 | 소규모 운영 | 제휴처 10곳, 결제/정산 자동화 |
| 3 | 확장 | 예약 연동, 지역 확장, 마케팅 자동화 |

Phase 1 시작 전에, 코드보다 먼저 **랜딩페이지 + 사전 신청/인터뷰**로 수요를 확인하는 것을 권장한다 (본업 병행 시 리소스 최소화 관점에서도 유리).

## 7. 기술 스택 (제안)

- 프론트: Next.js (React) — 랜딩페이지와 웹앱을 하나의 레포에서 단계적으로 확장하기 용이
- 백엔드/DB: Next.js API Routes + Supabase (Postgres, Auth, Storage) — 초기 인프라 운영 부담 최소화
- 결제: 토스페이먼츠 정기결제(빌링) API
- 배포: Vercel

이 스택은 1인 개발 + 야간/주말 작업에 적합하도록 운영 부담이 적은 조합 위주로 선정했다.
