# 디자이너 매출 진단 리포트 — 기능 스펙 (A그룹)

> 작성일: 2026-09-16
> 위치: `docs/chairgross/PLANNING.md` 11장(진단 리포트 우선순위)의 상세 스펙
> 범위: 위닛헤어스튜디오(라이브엑스) 리포트 벤치마킹 항목 중 "지금 바로 구현 가능(A그룹)"으로 분류된 8개 요소의 확정 사양

## 설계 원칙: 필수/선택 2단계 입력

라이브엑스 리포트는 프랜차이즈 본사 관리자가 CRM을 보고 데이터를 입력해주는 구조다. 체어그로스는 **개인 디자이너가 스스로 입력**해야 하므로, 항목을 세분화해서 요구하면 입력 피로도 때문에 사용을 포기할 위험이 크다. 이를 해결하기 위해 입력을 2단계로 계층화한다.

| 단계 | 입력 항목 | 소요시간 | 열리는 기능 |
|---|---|---|---|
| **필수** | 총매출, 총접객수 (합계만) | 30초 이내 | KPI 카드 4종(객단가는 자동계산), 매출 잠재력(기본형) |
| **선택** | 신규/재방문 인원 분리, 서비스/사전결제/리테일 매출 분리 | +1분 | 원인 분해 카드, 고객구조 카드, 더 정밀한 매출 잠재력 계산 |

선택 항목을 입력하지 않아도 해당 카드가 사라지지 않고, **"입력하면 이 진단이 열립니다"라는 잠금 안내**로 표시한다. 최소 입력만으로도 서비스는 항상 정상 작동해야 하며, 더 정교한 진단은 추가 입력에 대한 자연스러운 동기로 유도한다.

## 용어 변경 (라이브엑스와 중복 방지)

| 라이브엑스 원문 | 체어그로스 용어 |
|---|---|
| 시술 매출 | 서비스 매출 |
| 선불권 판매 | 사전결제(멤버십) 매출 |
| 점판 매출 | 리테일 매출 |

## 확정 스펙

### 1. 헤더
디자이너명 · 관측기간 · 업데이트일 3요소로 구성.

### 2. KPI 카드 4종 (총매출·접객수·객단가·일평균매출)
**로그인 후 첫 화면(홈 대시보드)**의 최상단에 배치한다. 홈 화면 = 이 KPI 카드가 있는 화면이라는 뜻이며, 별도의 "리포트 페이지"가 아니라 로그인 시 바로 보이는 히어로 뷰다.
- 데이터가 없는 최초 로그인 시: "첫 데이터를 입력해주세요" 빈 상태(empty state) 노출
- 필수 입력(총매출, 총접객수)만으로 생성 가능. 객단가 = 총매출 ÷ 총접객수로 자동 계산.

### 3. 원인 분해 카드 (서비스/사전결제/리테일 매출 증감)
**선택 입력**일 때만 열리는 카드. 미입력 시 잠금 안내로 대체.

### 4. 고객구조 카드 (신규/재방문)
**선택 입력**일 때만 열리는 카드. 미입력 시 잠금 안내로 대체.

### 5. 매출구성 비율
홈 대시보드 내 KPI 카드 옆 또는 아래에 도넛/막대 차트로 상시 노출 (선택 입력 데이터 있을 때만 표시).

### 6. 매출 잠재력 (구 "성장여력 계산기")
"이 지표만 개선하면 +OO만원"이라는 반사실적 계산을 자동 산출해 홈 대시보드에 상시 노출. 필수 입력만으로도 기본형 계산이 가능하고, 선택 입력이 있으면 더 정밀해진다.

### 7. 운영목표 KPI 카드
홈 대시보드에 "이번 달 목표 vs 실제"로 2번 KPI 카드와 나란히 배치.

### 8. 산식·해석범위 고지
쉬운 말로 순화한 문구로 작성. 매번 펼쳐서 보여주면 정보 과다이므로 평소엔 접혀 있다가 클릭 시 펼쳐지는 아코디언 형태로 배치.
